# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/TensorQuay/tensorquay-engine/security/advisories/new)
for security issues. Include a minimal reproducer, affected revision and impact. Do not include live credentials,
private prompts or customer data. Avoid public issues for undisclosed vulnerabilities.

This project is in the foundation stage; it does not yet provide a production inference server. Security fixes
currently target `main`. Supported releases and their maintenance policy will be documented when releases exist.
